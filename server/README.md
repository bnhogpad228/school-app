# Сервер «Школьного двора» — как развернуть в Yandex Cloud

Сервер — это одна функция (`index.js`), которая хранит события (сообщения, жалобы, скрытия,
объявления, занятые ники) в приватном бакете Object Storage. Каждое событие — отдельный файл,
поэтому одновременные сообщения не теряются. Приложение раз в 4 секунды спрашивает «что нового».

## Шаги в консоли (≈15 минут)

1. **Бакет для данных.** Object Storage → «Создать бакет»:
   имя `shkolny-dvor-data`, размер 1 ГБ, класс «Стандартное»,
   доступ к чтению объектов, к списку объектов и к настройкам — **«С авторизацией»** (данные учеников не должны быть публичными).
2. **Сервисный аккаунт.** «Сервисные аккаунты» (Identity and Access Management) → «Создать сервисный аккаунт»:
   имя `shkolny-dvor-api`, роль **`storage.editor`**.
3. **Функция.** Cloud Functions → «Создать функцию», имя `shkolny-dvor-api` → «Редактор»:
   - среда выполнения: **Node.js 22** (подойдёт и 18 — нужна встроенная `fetch`);
   - способ: редактор кода; в файл `index.js` вставить содержимое `server/index.js`;
   - точка входа: `index.handler`;
   - таймаут: 10 с, память: 128 МБ;
   - сервисный аккаунт: `shkolny-dvor-api`;
   - переменные окружения: `BUCKET` = `shkolny-dvor-data`, `SCHOOL_CODE` = `1234`, `MOD_CODE` = `5678`;
   - «Сохранить изменения».
4. **Сделать функцию публичной.** Вкладка «Обзор» → переключатель «Публичная функция».
5. **Проверить.** Открыть в браузере «Ссылку для вызова» с `?code=1234` на конце,
   например `https://functions.yandexcloud.net/d4e...?code=1234`. Должно показать `{"events":[]}`.
6. **Подключить к сайту.** В `sync.js` вписать ссылку в `SERVER_URL_DEFAULT` и выложить сайт заново.
7. **Бюджет.** Биллинг → «Бюджеты» → уведомление, например, на 100 ₽ — чтобы не было сюрпризов.

## Что сервер проверяет

- Без кода школы читать и писать нельзя.
- Скрывать сообщения и делать объявления — только с кодом модератора.
- Принимаются только известные типы событий и разрешённые поля; текст — до 500 символов.
- Время события ставит сервер.

## Честные ограничения прототипа

- Аккаунты (ник + пароль) хранятся на телефоне; сервер только помнит, что ник занят.
- Коды есть в коде приложения — в боевой версии вход шёл бы через сервер со своими аккаунтами.
- Личные сообщения между разными телефонами — следующий шаг (сейчас личка работает на одном телефоне).
